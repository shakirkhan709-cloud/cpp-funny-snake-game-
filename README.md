# 🎮 Gameplay

The player controls the snake using the keyboard arrow keys.

The objective is simple:

- Eat food (.)
- Grow longer
- Increase score
- Avoid walls
- Avoid your own tail
- Beat your previous High Score

Each food collected increases the score by **10 points**.

# ⚙️ How It Works

The application starts with a main menu.

From there, users can:

- Start Game
- Select Difficulty
- View High Score
- Read Instructions
- Exit

During gameplay:

- Snake moves using Arrow Keys.
- Random food appears inside the board.
- Eating food increases score.
- Snake grows.
- Collision ends the game.
- High score is automatically saved.

# 💾 High Score System

The project automatically stores the highest score inside:

```
highscore.txt
```

Whenever a player beats the previous record, the new score is saved automatically.

This allows the score to persist even after closing the game.
